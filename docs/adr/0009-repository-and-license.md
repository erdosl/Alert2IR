# ADR 0009: Repository and license

**Status:** Accepted

## Context

The project needs a clear public record of architecture, implementation, infrastructure definitions, and contribution terms.

## Decision

Maintain Alert2IR as a public monorepo and license it under Apache License 2.0. Git-tracked documentation and ADRs are the source of truth.

## Consequences

Changes across concerns can be reviewed together. Public history requires strict secret hygiene and accurate separation of plans from implemented features.
